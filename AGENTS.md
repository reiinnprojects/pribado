# Pribado

Agent skill for privacy drafts under the Philippine Data Privacy Act (RA 10173) and National Privacy Commission issuances. Not legal advice.

## Install

```bash
./install.sh
```

Copies `skills/pribado` to `~/.cursor/skills/pribado/`.

## Agents working in this repo

- Cite an issuance only when `skills/pribado/references/npc-issuances.md` lists that number and section. If it does not, say you are unsure and link the issuance.
- Write the draft. Do not edit the app the user asked you to review.
- Leave `TODO:` where only a person knows the fact: controller name, DPO contact, sites, registration.
